# Tier 2: Hardware-bound access

This tier preserves the available 1BIL hardware-bound access example. The case contains encrypted and authorized decrypted structural assets.

Run:

```bash
python audit_hardware_bound_case.py
```

Output:

- `hardware_bound_access_audit.csv`: file hashes, byte sizes and integrity checks showing that paired encrypted exports match and paired decrypted exports match.
